■ 今夜入れたもの (使い方)
- 常時命令 (A 段): strategist.ORDERS = save_healing (回復薬は HP 50% 未満だけ) / avoid_rusters (アクエーターの隣で休まない・拾わない・探索しない) / rest_before_stairs (HP 90% 未満なら降りない)
    指示役の JSON の orders に入る。意味は Strategist.order_drops で固定。sim.py の +orders:a,b で固定命令 (LLM なし) を測れる
- 記録と再生: sim.py が 1 秒ごとに data/replays/<頭脳>_<種>.json を書く (picks = fetch で拾いに行く種類も記録)
    uv run server.py --replay data/replays --no-open   ← 最新の記録を追いかける。サーバーで 1 本流して全タブに配信、F5 でも途中から
    記録の再現では g.valid_actions() を記録時と同じ順で呼び、g.pick_kind = picks[i] を入れてから step する (tools/trace_replay.py 参照)
- tools/trace_replay.py <記録> [N]: 文字で再生 (階ごとの要約・相談・末尾 N 手)。tools/death_causes.py <glob>: 死因の表
- 画面: テーマ T キー (LAYA ROGUE / DOS 16 色 / CGA 4 色 / xterm 風)。切断されたタブはサーバーが戻ると自動リロード
    server.py を直したら taskkill /PID <8766 の PID> → uv run server.py --replay data/replays --no-open (python.exe の一括 kill は sim を巻き添え)
- 退避した記録: data/llm16d/ (3 回目)、data/llm16e/ (4 回目)、data/valves/ (安全弁の基準)。全部 gitignore

■ 運用メモ
- 長い処理は PowerShell Start-Process で切り離す (Bash ツール 10 分制限)。bash スクリプト冒頭で PATH に /usr/bin。sim の python は優先度 High
- ファイルは CRLF。Windows パス入り Python は Write でファイルにしてから実行
- Desktop は Claude Code の permission settings で deny されていて書けない (deny を外す必要がある。allow を足すだけでは通らない)
